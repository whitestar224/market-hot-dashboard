# 监控入池 CA 核验与买入进度

- 在后台监控接入时登记链 + CA，独立有界队列核验并持久化元数据；跨重启复用，定期后台复核。
- 来源缺链/CA、互相冲突、元数据币名不匹配时不开买入，不通过同名搜索随意选地址。
- 买入面板锁定已核验身份；报价仅本地校验绑定，不重新解析目标 CA。余额、价格、合约风险、收款人、报价和签名权限仍实时复核。
- 进度按真实步骤更新，不把停止当作继续加载；失败原因放在进度主体，重试清理旧请求状态，钱包提交未知不得自动重发。
- 验证范围：身份队列/持久化/同名异链/身份篡改/网络故障，报价不调用远程身份解析，前端禁用与进度状态，既有买入安全回归。不签名、不转账、不实际买入。
