# 量化策略看板与交易 API 配置

## 目标

策略看板只负责把“热门上榜、首次结构、首次有效突破、人工确认、仓位试算”串成一条可审计流程。所有真实交易操作必须经过人工确认，不允许页面自动下单。

## 信号流程

1. AICoin 热门榜新增币种进入价格监控。
2. 服务端识别持续至少 3 小时的可定义结构。
3. 价格第一次有效突破结构高点后进入待确认状态。
4. 用户人工确认信号有效。
5. 系统依据账户权益、保证金、杠杆和突破口下方 3% 止损计算名义仓位、下单数量和最大风险；突破口统一取最近 7 日前高。
6. 用户二次确认后创建模拟订单；真实订单适配器启用前不得发送交易所订单。

## 交易所优先级

固定优先级为 Binance、OKX、Bitget。若高优先级交易所未配置而低优先级交易所已配置，页面优先推荐已经配置且排序最高的交易所。

## 凭证安全

- API Key、Secret 和 Passphrase 按用户隔离保存。
- 数据库存储使用 AES-GCM 字段加密。
- 前端只读取配置状态和 Key 掩码，不回显 Secret 或 Passphrase。
- 删除配置只删除当前用户、当前交易所的数据。
- 服务端环境变量仅作为管理员预置的备用配置。

## 风控边界

- 单笔风险、总敞口、杠杆和日内亏损上限均在服务端重新计算。
- 止损固定为突破口下方 3%，页面不能覆盖服务端风控结果。
- 保本操作需要二次确认。
- 真实交易默认关闭；即使 API 已配置，也必须显式启用并完成交易所签名适配器后才能发送真实订单。
