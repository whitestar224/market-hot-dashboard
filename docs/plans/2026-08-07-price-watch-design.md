# 币种价格监控设计

## 目标

- 自动记录最近 7 天首次进入 AICoin 热门榜前十的加密币种。
- 支持手动添加或移除，自动与手动合计最多 20 个。
- 使用最近 7 天的小时 K 线计算前高，当前价必须低于前高且距离不超过 3% 才触发预警。
- 同一标的回撤离开预警区后再次进入、突破后回踩新高，或前高实质抬升后再次靠近，均允许重新触发。
- 预警同时进入 Windows 左下角弹窗队列，并推送到 Discord 热门币监控频道。

## 数据与状态

- `price_watch_assets` 保存监控来源、首次上榜时间、行情快照和检查状态。
- `price_watch_alert_state` 保存行情阶段、离开预警区时间和预警序号，防止每分钟重复提醒。
- 自动标的保留 7 天；手动标的不受 7 天到期限制。
- 自动列表排除稳定币、站点排除币种、代币化股票和贵金属等非加密标的。

## 行情策略

- 所有标的统一使用 USDT 合约小时 K 线，不混用现货价格。
- 固定按 Binance U 本位合约、OKX 永续、Bitget USDT 合约的顺序查询；前一交易所没有该合约或暂时不可用时自动回退。
- 最近一个未完成小时 K 线不参与前高计算，仅用于当前价格。

## 提醒策略

- Windows 提醒沿用全站队列，连续提醒至少间隔 75 秒并固定在左下角。
- 同一行情阶段只提醒一次；重新接近时至少间隔 15 分钟，过滤 3% 边缘的价格抖动。
- Discord 同一轮多个预警合并发送，且禁止 `@everyone` 等提及。
- Webhook 仅保存在被 Git 忽略的 `.env` / `.env.production` 中。

## 验收

- 页面首次打开先显示数据库快照，后台按分钟更新。
- 手动添加、移除、刷新均不要求登录。
- 当前价等于或高于前高时不显示“接近前高”预警。
- 重复轮询不重复推送；离开 3.25% 重置区、突破旧高或形成显著新高后再次进入才重新提醒。
