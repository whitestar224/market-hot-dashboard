# 系统自优化检查设计

系统每 30 分钟执行一次轻量只读检查，检查范围包括数据源健康、近期错误、代码体积与复杂度、测试覆盖、监控遗漏、去重、持久化、性能、AI 成本和页面交互。检查先生成稳定指纹；项目与运行状态没有实质变化时不重复调用 AI。一次分析可以形成多个候选建议，但每轮最多弹出一条，且相同建议在冷却期内不重复播报。

弹窗只展示一个证据充分、范围可控的改进建议，包含问题、改进方向和预期收益。关闭弹窗不会改动系统。只有点击“确认优化”才会向本机接口提交建议编号和版本；接口只接受本机或管理员请求，并用运行锁阻止重复任务。

确认后，本地 Codex CLI 在项目的临时副本中工作，不能访问浏览器、Computer Use、插件、密钥文件或运行数据。提示词限定只实现已确认建议，不得扩大功能、删除现有行为、提交或推送代码。优化结果必须通过 Python/JavaScript 语法检查；改动文件数量和类型也受限制。验证通过后，系统仅在真实项目文件仍与检查前一致时应用改动，避免覆盖用户同时进行的编辑，并为被替换文件保留有限数量的本地备份。

任务状态、建议历史、去重指纹、执行结果和错误都会持久化。优化完成或失败会再次弹窗说明结果；涉及后端代码时提示下次重启生效，不进行不可控的强制重启。
