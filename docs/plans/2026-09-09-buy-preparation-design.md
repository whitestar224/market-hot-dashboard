# 买入提速、供应商错误与标题 CA

本轮需求同时保留：输入金额即可点击买入、后台提前准备；核查币安参数错误与 Relay 20% 提示；标题旁显示完整 CA。

选择：复用现有全局钱包余额预读，悬停/聚焦/打开买入时预备已核验标的的安全信息及 USDT 参考价格；输入金额启动精确只读报价；点击买入复用同一在途请求。未就绪时按钮接受用户意图，但仍等待实际报价通过后才请求钱包。修改金额/关闭/换钱包取消意图，输入本身绝不自动签名。

不选择：为所有标的及所有金额持续刷报价（限流且浪费）；直接复用旧金额 calldata 或取消最终检查（无法保证扣款/最低到账）。非托管逐笔确认、20% 上限、精确授权、原有 Gas/价格冲击保护不变。

只读复现：币安 autoSlippage 与 slippagePercent 同时传递返回 40001，原文 mutually exclusive；仅传 autoSlippage + maxAutoSlippagePercent 成功，约 5.12%。文档描述覆盖但实际接口互斥，以实测为准。Relay 同源链新报价 2000bps/500bps 均正确，历史失败无法仅从截图还原；拆开缺字段、最低到账不满足、容忍度超限三类原因，标明供应商与付款链，不伪称实际亏损。

验收：参数互斥回归；最低到账与容忍度分类/20% 硬限；预备不创建订单/不调用钱包；在途报价复用、修改/关闭/换钱包取消、重复点击无重复执行；已模拟的同一不可变订单仅10秒内复用，绝不续期，过期/授权后重新模拟；完整 CA 不截断且可复制，窄屏换行；构建、只读真实报价与上线验证分开记录，不自动交易。
