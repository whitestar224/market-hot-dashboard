# 产业链瓶颈龙头战法 Skill

这是一个用于产业链选股和龙头战法执行的 Skill 包。

## 文件结构

- `SKILL.md`：核心 Skill 说明、流程、评分模型和输出规范。
- `templates/产业链反推表.md`：从大龙头或新闻向下拆产业链。
- `templates/单票研究卡.md`：研究单只股票的结构化模板。
- `templates/候选池评分表.csv`：候选池评分模板。
- `templates/每日执行清单.md`：每日复盘和执行模板。

## 使用方式

在支持 Skills 的环境中，将整个文件夹作为一个 Skill 使用。

推荐调用语：

```text
启动产业链瓶颈龙头战法，分析【主题/股票/新闻】，给我产业链反推、候选池、总龙/分支龙/补涨判断、买点和风险。
```
