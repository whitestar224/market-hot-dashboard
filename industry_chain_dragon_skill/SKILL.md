# 产业链瓶颈龙头战法 Skill

## 0. 核心定义

这个 Skill 用来做一件事：

**从一个时代级主线或核心龙头出发，向产业链深处反推“物理瓶颈”，再把瓶颈映射到上市公司，最后用龙头战法筛出真正能走主升的票。**

合体后的方法不是单纯找题材，也不是单纯追涨，而是：

> 时代级需求爆发 → 系统压力传导 → 物理瓶颈出现 → 稀缺供应商受益 → 小市值/低认知错配 → 资金确认 → 龙头走主升 → 用横盘起飞/情绪周期执行。

白毛提供的是 **选股源头**：从产业链和瓶颈找股票。
龙头战法提供的是 **交易执行**：从强度、结构、情绪周期确认谁是真龙。

---

## 1. 适用场景

当用户提出以下问题时，启动本 Skill：

- “看到某个龙头，怎么反推出更深层股票？”
- “用白毛思路分析某个产业链。”
- “把某个题材拆成可交易的候选股。”
- “这个新闻背后有哪些小市值瓶颈票？”
- “帮我找某个主线的总龙、补涨、卡位。”
- “把某个股票/产业放进龙头战法里分析。”
- “复盘某段历史行情，并提炼选股框架。”

如果涉及实时行情、公司公告、持仓披露、财报、价格、成交量、上市地、代码、监管变化，必须使用最新数据源验证，不要凭记忆回答。

## 2. 合体后的总框架

### 2.1 白毛部分：产业链瓶颈反推

从主线龙头往下拆，不要停留在一级概念。

标准链条：

```text
终端需求
→ 系统扩张
→ 新增压力
→ 物理瓶颈
→ 新增 BOM
→ 关键零部件/材料/设备
→ 稀缺供应商
→ 上市公司映射
```

示例：

```text
NVIDIA GPU 爆发
→ AI 数据中心扩张
→ GPU 集群互联压力上升
→ 带宽/功耗/散热/距离成为瓶颈
→ 光互联/CPO/硅光需求提升
→ 外置激光源/DFB laser array 变关键
→ 寻找小市值上游供应商
```

白毛部分重点回答：

1. 这个主线是不是真时代级增量？
2. 增长会把压力传导到哪里？
3. 哪个环节最容易供不应求？
4. 这个瓶颈对应什么零部件/材料/设备？
5. 哪些公司卡在这个位置？
6. 其中有没有小市值、低关注度、被机构重新定价的对象？

---

### 2.2 龙头战法部分：市场强度确认

产业链反推只能给出“候选池”，不能直接等于买点。
真正参与前，必须用龙头战法确认它是不是市场选择出来的龙头。

标准链条：

```text
产业逻辑成立
→ 候选池出现
→ 股价强度排名
→ 成交额/换手/流动性确认
→ 板块联动确认
→ 情绪周期确认
→ 结构买点确认
→ 风控位确认
```

龙头战法重点回答：

1. 它是不是同主线里涨幅、成交额、辨识度最强的？
2. 它是总龙、分支龙、补涨，还是纯跟风？
3. 当前处在启动、主升、高潮、退潮、冰点中的哪一段？
4. 是否出现横盘起飞、放量突破、换手承接、强势回踩等结构？
5. 一旦走弱，失效条件是什么？

## 3. 五层反推法

每次看到一个大龙头或大新闻，至少拆到第五层。

| 层级 | 问题 | 输出 |
|---|---|---|
| 第 1 层：终端需求 | 谁在花钱？为什么花？ | 云厂商、数据中心、车企、运营商、军工、消费端等 |
| 第 2 层：系统扩张 | 需求增长会让什么系统变大？ | 服务器、网络、电力、封装、生产线、仓储等 |
| 第 3 层：物理瓶颈 | 规模扩大后卡在哪里？ | 带宽、功耗、散热、良率、产能、材料、设备、认证等 |
| 第 4 层：关键 BOM | 哪些零部件/材料/设备变关键？ | 芯片、光模块、激光器、基板、液冷、电源、设备等 |
| 第 5 层：股票映射 | 哪些上市公司直接受益？ | 总龙、中军、小票、海外冷门票、OTC 票 |

原则：

**只拆到“AI”或“新能源”这种一级概念，等于没有拆。必须拆到具体零部件、材料、设备、供应商。**

## 4. 候选股评分模型

总分 100 分。分数不是买入建议，只用于候选池排序。

### 4.1 产业瓶颈分：40 分

| 指标 | 分值 | 判断标准 |
|---|---:|---|
| 时代需求强度 | 8 | 是否由大规模 CapEx、技术代际升级、政策/产业趋势推动 |
| 瓶颈清晰度 | 8 | 是否能明确说明“为什么缺、缺在哪里、谁离不开它” |
| BOM 必要性 | 6 | 是否是系统不可替代的关键环节，而非可有可无的配套 |
| 供给稀缺度 | 6 | 供应商是否少、验证周期是否长、客户切换是否难 |
| 产业验证 | 6 | 是否有大客户、合作、订单、认证、设计导入、量产进展 |
| 收入弹性 | 3 | 行业增长能否真实传导到公司收入/利润 |
| 认知差/市值错配 | 3 | 市场是否还没有充分定价，市值是否足够小以产生弹性 |

### 4.2 市场龙头分：30 分

| 指标 | 分值 | 判断标准 |
|---|---:|---|
| 相对涨幅 | 8 | 同板块/同链条里是否涨幅领先 |
| 成交额/换手 | 5 | 是否有真实资金参与，避免无量小票 |
| 趋势结构 | 6 | 是否主升、横盘起飞、放量突破、强势回踩不破 |
| 辨识度 | 5 | 是否成为市场讨论焦点、板块锚点或情绪核心 |
| 联动带动性 | 3 | 它涨是否能带动同链条其他票 |
| 抗跌性 | 3 | 板块回调时是否更强，是否先于板块修复 |

### 4.3 催化和筹码分：15 分

| 指标 | 分值 | 判断标准 |
|---|---:|---|
| 近期催化 | 5 | 财报、订单、发布会、产业会议、监管节点、产品验证 |
| 机构/资金信号 | 4 | 持仓披露、定增、战略投资、产业资本、ETF 纳入等 |
| 筹码结构 | 3 | 流通盘、锁仓、做空比例、融资压力、解禁压力 |
| 信息扩散度 | 3 | 是否正在从小圈层扩散到大众市场 |

### 4.4 风险折扣：-20 到 0 分

| 风险 | 扣分参考 |
|---|---:|
| 逻辑只停留在故事，没有客户/订单/验证 | -5 到 -10 |
| 已经数倍上涨，进入高潮末期 | -5 到 -10 |
| 流动性太差、点差太大、OTC/小市场交易困难 | -3 到 -8 |
| 高度依赖单一客户或单一项目 | -3 到 -6 |
| 增发、债务、亏损、现金流压力 | -3 到 -8 |
| 机构披露可能只是托管/衍生品/客户仓位，不是真主动买入 | -2 到 -5 |
| 产业周期可能从短缺转向过剩 | -5 到 -10 |

### 4.5 分数解释

| 总分 | 解释 |
|---:|---|
| 85+ | 产业逻辑强 + 市场确认强，重点跟踪，不等于追高 |
| 75-84 | 高质量候选，等待结构买点或催化验证 |
| 65-74 | 有逻辑但仍需观察，可能是分支龙/补涨 |
| 50-64 | 逻辑或强度不完整，只能放入观察池 |
| <50 | 过滤，除非出现重大新催化 |

## 5. 龙头分类

### 5.1 总龙

同时满足：

- 处于最强主线或最强分支。
- 产业链位置最硬，最好卡瓶颈。
- 股价强度、成交额、辨识度领先。
- 能带动板块，而不是被板块带着走。
- 回调时抗跌，修复时先涨。

总龙优先级最高，但不能无脑追高。总龙的最佳参与点通常是：

```text
启动确认 → 横盘换手 → 再次放量突破 → 主升延续
```

### 5.2 分支龙

满足：

- 不是整条主线最强，但在某个细分瓶颈里最强。
- 例如 AI 主线里的 CPO、液冷、电力、HBM、先进封装各自分支龙。
- 适合主线扩散阶段、总龙高位震荡阶段。

### 5.3 补涨

满足：

- 同产业链逻辑相似，但启动更晚。
- 市值更小，认知更低。
- 通常在总龙涨高后被市场挖掘。

补涨只能在板块情绪仍强时做。退潮期补涨最容易坑人。

### 5.4 卡位

满足：

- 原龙头走弱或逻辑边际变差。
- 新瓶颈、新催化、新订单、新市场开始出现。
- 新票强度反超旧龙头。

卡位不是主观幻想，必须由盘口和强度确认。

## 6. 情绪周期执行规则

### 6.1 主升期

特点：

- 主线持续扩散。
- 总龙不断新高。
- 分支龙轮动补涨。
- 新闻和资金形成正反馈。

执行：

- 重心放在总龙和最强分支龙。
- 优先做横盘起飞、强势回踩、放量突破。
- 少碰杂毛，少做低位纯补涨。
- 趋势没坏之前，不轻易被小波动洗走。

### 6.2 震荡期

特点：

- 主线还在，但持续性下降。
- 龙头高位震荡，分支轮动加快。
- 容易日内冲高回落。

执行：

- 降低仓位和预期。
- 做小龙、分支龙、强势反包、底部反转。
- 盈利后更强调兑现。
- 不在震荡期把补涨当总龙。

### 6.3 主跌期

特点：

- 总龙破位。
- 板块联动转弱。
- 利好不涨，反弹无量。

执行：

- 原则上回避多头。
- 只做确定性很高的反向交易或空头结构。
- 不用产业逻辑给亏损找理由。

### 6.4 反弹期

特点：

- 板块从冰点修复。
- 最强旧龙或新分支先反弹。
- 延续性不确定。

执行：

- 只做高辨识度对象。
- 不追后排。
- 以短周期确认强度，利润先落袋一部分。

### 6.5 冰点期

特点：

- 资金风险偏好极低。
- 龙头补跌。
- 大多数题材无持续性。

执行：

- 以观察为主。
- 只记录谁抗跌、谁先修复。
- 冰点转强时，第一批走出来的才值得重点看。

## 7. 横盘起飞结构

横盘起飞是本体系的核心执行结构。

### 7.1 有效横盘起飞

至少满足：

1. 前面有一段明确强势上涨，证明资金已经选择它。
2. 横盘期间没有深度破位，说明承接强。
3. 成交量逐步收敛或换手充分。
4. 再次突破时放量，且能站稳关键区间。
5. 同板块或同主线没有明显退潮。

### 7.2 无效横盘起飞

以下情况要小心：

- 已经高潮后高位横盘，但板块情绪在退潮。
- 横盘期间不断放量滞涨。
- 只是一根消息刺激阳线，没有持续资金。
- 后排补涨冒充龙头。
- OTC/小市场股票流动性太差，突破可能是假信号。

### 7.3 买点分级

| 买点 | 条件 | 风险 |
|---|---|---|
| A 类 | 主线主升 + 总龙横盘起飞 + 放量突破 | 最优 |
| B 类 | 分支龙强势回踩不破 + 再转强 | 中等 |
| C 类 | 补涨首板/首阳/首突破 | 依赖情绪 |
| D 类 | 高潮后追涨 | 高风险，原则上不做 |

## 8. 研究流程

### 8.1 从新闻开始

拿到一条新闻时，不要只看表面股票。

按这个顺序拆：

```text
新闻说了什么？
→ 它对应哪个时代级主线？
→ 它会增加哪个系统的需求？
→ 系统扩大后卡在哪里？
→ 哪些零部件/材料/设备变成瓶颈？
→ 哪些公司直接供货或有验证？
→ 这些公司谁最小、最强、最可能被重估？
→ 股价是否已经确认？
```

### 8.2 从龙头开始

看到 NVIDIA、TSMC、Microsoft、Tesla、Amazon 这种大龙头时，不要只问它还能不能涨。

要问：

```text
它增长会让谁受益？
它扩张会让哪个环节缺货？
它的 CapEx 会流向哪些供应商？
它的下一代架构新增了哪些 BOM？
它的供应链里有没有冷门上市公司？
```

### 8.3 从涨幅榜开始

涨幅榜不是用来无脑追，而是用来发现市场正在选择什么。

步骤：

1. 找 24h / 5d / 20d 最强股票。
2. 给它们归类到产业链层级。
3. 判断上涨原因是产业瓶颈、事件催化，还是纯情绪。
4. 看是否出现同链条扩散。
5. 最后再用横盘起飞或回踩结构参与。

## 10. 反证清单

任何看起来很强的票，都必须问反证。

1. 这个公司是不是真的卖这个东西，还是只是在 PPT 里蹭概念？
2. 它的产品是不是关键瓶颈，还是替代品很多？
3. 它有没有真实客户、订单、认证、设计导入？
4. 收入弹性能不能体现到财报？
5. 是否存在增发、债务、现金流问题？
6. 现在是启动、主升，还是高潮末期？
7. 机构持仓披露是否可能只是托管、做市、衍生品或客户仓位？
8. 如果行业从短缺转向过剩，它会不会是杀估值最狠的？
9. 这只票有没有足够流动性让你进出？
10. 如果买错，在哪里承认错误？

## 11. 风控规则

1. 产业逻辑再强，也不能替代止损。
2. 小市值瓶颈票弹性大，但流动性和回撤也更大。
3. 不在高潮末期用“长期逻辑”给短线追高找理由。
4. 不把补涨当总龙，不把消息票当产业瓶颈票。
5. 单笔亏损必须可控，不能出现一次交易伤筋动骨。
6. 主升期可以重视趋势，震荡期必须降低预期，主跌期必须尊重破位。
7. 买入前必须写出失效条件，买入后只按失效条件执行，不临场自我欺骗。
8. 对 OTC、北欧小票、低流动性票，要额外考虑点差、汇率、交易权限和滑点。

## 12. 最终心法

### 12.1 白毛心法

```text
不要买最热闹的表面故事，要买时代扩张后绕不开的底层瓶颈。
```

### 12.2 龙头战法心法

```text
逻辑只决定候选，价格强度才决定谁是真龙。
```

### 12.3 合体心法

```text
从产业链深处找瓶颈，从市场强度里找龙头，从情绪周期里找买点，从失效条件里守本金。
```
